# CleanHub — Марти Хигиена

ASP.NET Core 8 (MVC + Razor) апликација за управување со згради, станари, фактури и книжења.

## Изглед

- Сите стилови се во **една датотека**: `wwwroot/css/site.css` (светла и темна тема).
- Глобалните скрипти се во `wwwroot/js/site.js` (DataTables, датуми дд.мм.гггг, тема, мени).
- PDF шаблоните (`Views/Shared/_DocumentDetailPartial*.cshtml`, `Views/Ai/_AnnualReportPdf.cshtml`)
  имаат свои вградени стилови бидејќи SelectPdf не ја вчитува `site.css`.

## AI алатки (мени „AI алатки“)

| Страна | Што прави |
|---|---|
| **Прашај ја апликацијата** (`/Ai/Assistant`) | Прашања на македонски („Кои станари не платиле 3 месеци?“). AI НЕ пишува SQL — користи само алатки што читаат податоци (AsNoTracking). Ништо не може да се измени. |
| **Потсетници за долг** (`/Ai/Reminders`) | Должници по ниво: 1 месец = љубезно, 2 = потсетник, 3+ = опомена. AI пишува лична порака, вие ја прегледувате/менувате и ја праќате по е-пошта. SMS и Viber се отвораат на уредот со готов текст. |
| **Извештај за грешки** (`/Ai/Anomalies`) | Двојни уплати, згради (партнери со дејност 2) без фактура минатиот месец, необично големи трошоци, негативно салдо кај станари што не се во претплата + AI резиме. Секој понеделник автоматски на е-пошта. |
| **Годишен извештај** (`/Ai/AnnualReport`) | Извештај за собрание на станари: бројките ги пресметува апликацијата, AI го пишува текстот. Преглед + PDF. |

Сите бројки ги пресметува C# кодот. AI само пишува текст и не смее да измислува износи.
До AI се праќаат само имиња, периоди и износи — без е-пошта, телефон или ЕМБГ.

### Поставување

Клучот **никогаш** не се става во `appsettings.json` (тој е во git). Користете user-secrets или променлива на околина:

```bash
# Локално (Development)
dotnet user-secrets set "AI:ApiKey" "sk-ant-..."

# Сервер (IIS / Azure / Linux) — променливи на околина
AI__ApiKey=sk-ant-...
AI__WeeklyReportRecipient=kancelarija@primer.mk     # повеќе адреси со , или ;
AI__WeeklyReportHour=8                               # час во Скопје (стандардно 8)
AI__Model=claude-sonnet-5-5                          # опционално
```

- Без `AI:ApiKey` сè работи, но пораките/текстовите се од готови шаблони, а асистентот е исклучен.
- Без `AI:WeeklyReportRecipient` неделниот извештај не се праќа автоматски
  (рачно праќање оди на `SMTP:Recipient`).
- Е-поштата се праќа од `SMTP:Email` преку постоечките `SMTP` поставки (исто како фактурите).

### Тестирање на е-пошта

Е-поштата се праќа **исто како „Зачувај, прати и принтај“** (`SMTP:Server`, `SMTP:Email`, `SMTP:Passwort`).
За тест: во „Потсетници за долг“ генерирајте порака, во полето за е-пошта на картичката внесете
**своја** адреса и кликнете „Е-пошта“ — пораката оди само таму.

### SMS преку Telnyx

Во „Потсетници за долг“ секоја порака има кратка SMS верзија со бројач на SMS делови.
SMS **секогаш** се праќа на латиница (автоматска транслитерација) — 160 знаци по SMS наместо 70, до 2× поевтино. Поставки (user-secrets / env, никогаш во appsettings.json):

```bash
dotnet user-secrets set "Telnyx:ApiKey" "KEY..."
dotnet user-secrets set "Telnyx:From" "MartiHigien"                 # Alpha sender, до 11 знаци
dotnet user-secrets set "Telnyx:MessagingProfileId" "4001..."        # ID на Messaging Profile
```

За Македонија не треба купен број — се праќа со името (Alphanumeric Sender ID). Станарите не можат да одговорат на SMS.
Без `Telnyx:ApiKey` копчето отвора SMS апликација на уредот.

### Ограничувања

- Viber не се праќа автоматски — копчето ја копира пораката и го отвора разговорот.
- Неделниот извештај памети дали е пратен само во меморија: ако апликацијата се рестартира во понеделник по 8 часот, може да се прати повторно.
